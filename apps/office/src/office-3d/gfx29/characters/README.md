# Premium characters

`createPremiumCharacter({ employeeId, deskId, status })` returns a Three.js Group with semantic `userData` and methods `updateData`, `updateAnimation(timeSeconds, state)` and `dispose`. The caller owns placement, picking and the renderer. Call `updateAnimation` from the shared render loop; its boolean indicates a changed pose. `{ enabled: false }` or `{ reducedMotion: true }` restores the static pose. Appearance is derived only from the stable employee ID and remains unchanged across status and desk updates. An identity change requires a new instance.

Place the root at the actual chair centre at floor level, with local -Z toward the desk. Do not place it at `characterSpot`: the current layout's spot is behind the chair. For Floor 02 resolve the chair using each employee's `deskId`, transform layout coordinates to world coordinates as in the scene, and apply the desk's orientation. Keep the existing employee data source and selection handler. Remove the old GLB/fallback character for each employee when integrating. This module does not create employees or a render loop.

The preview loads the actual `v1/office-pack.glb` desk, chair, monitor and keyboard and the authoritative showroom employee assignments. Existing asset bounds are approximately desk 1.516 × 0.915 × 0.736 m, chair 0.626 × 1.302 × 0.675 m, monitor 0.640 × 0.485 × 0.220 m, keyboard 0.643 × 0.053 × 0.200 m. The pose is tuned for the showroom's current placement and requires rechecking if furniture or layout changes. It is a stylized procedural prototype, not a skinned character asset.
