# MAO-GFX-29-B2 — ARCHITECTURE REFINEMENT REPORT

Статус: **PARTIAL по художественному соответствию**. Критические технические дефекты исправлены, существующий модуль переработан, две GLB-итерации и визуальное сравнение выполнены. Полное качество утверждённого изображения пока не достигнуто: skyline и настенный декор заметно условнее PNG, а вся сцена с существующим pack и освещением выглядит проще эталона.

Изменения исключительно в `gfx29/architecture/`. Основная сцена, lighting, layout engine, персонажи, публичный pack, конфигурации и зависимости не редактировались. Commit/push/reset/clean и production build не выполнялись.

## 2. Исправления геометрии

Проёмы точно X −7.4…−1.2 и 1.2…7.4, Y 1.1…4.4 относительно `floorY`. Стекло шириной 6.04 м вписано внутрь каждого проёма с боковым отступом .08. Рамы толщиной .08 и глубиной .19 м, две внутренние стойки, импост, деревянный подоконник глубиной .56 и фартук.

Кладка с шагом ряда .22 и разбежкой .24 м. Кирпич и раствор обрезаются по одному контракту проёмов: сплошной кирпичной плоскости за стеклом нет. Дополнительные лучи X −8, 0, 8 подтверждают наличие простенков.

Ковры опираются на `floorY + .006`, их верх около `floorY + .0335`. Мебель на коврах — `floorY + .035`. Опора вычисляется по настоящему Box3 каждого GLB, а не по предположению о pivot.

## 6. Асинхронный asset API

Переработан тот же `createPremiumArchitectureV29`, второй реализации нет. Теперь возвращает **Promise<PremiumArchitecture>**; `cloneAsset` может возвращать Object3D или Promise. Синхронные поставщики клонов совместимы, но сам factory всегда await.

`createArchitectureAssetAdapter(runtime)` вызывает await `createInstance(id)`, сохраняет семантические роли материалов, затем await `applyMaterials`. При ошибке материалов немедленно вызывает `disposeInstance` для полученного объекта.

Группа остаётся detached до полной загрузки всех обязательных assets. Ошибки получают `code`/`assetId`, уже полученные экземпляры и собственные ресурсы освобождаются. Нет молчаливой подмены кубами или неполной успешной комнаты. Missing/empty/reused/parented objects отклоняются. AbortSignal проверяется до/после загрузок; поздний объект после abort тоже освобождается. Внутренний HTTP запрос runtime отменить нельзя — API не предоставляет такого контракта.

## 12. Оставшиеся отличия от референса

- Skyline имеет настоящую глубину, но его здания и деревья проще города PNG. Настенные GLB картины абстрактные, не пейзажи.
- Существующий pack A имеет более условные материалы, растительность и силуэты. Модуль не выдаёт их за точную копию сложного интерьера PNG.
- В PNG переговорная имеет кольцевой подвес; настоящий доступный GLB — купольный.
- В эталоне центральные рабочие места визуально крупнее относительно пола. Их layout и identities сохранены; архитектура не масштабирует рабочие места.
- Preview использует модуль D с локальными параметрами. Тени и вечерняя атмосфера ещё отличаются от PNG; production lighting/controller не редактировались.
- Интеграция в OfficeScene3D не входит в разрешённые изменения. Metadata подготовлена для выборочной замены; отсутствие старых дублей в основном приложении проверяется после подключения интегратором.

Из-за художественной разницы итоговый статус PARTIAL, несмотря на исправленные критические дефекты и прошедшие инженерные проверки.

## 13. Точный публичный API для интегратора

```ts
import { createPremiumArchitectureV29, createArchitectureAssetAdapter } from './gfx29/architecture';
const architecture = await createPremiumArchitectureV29({
  floorBounds: { minX: -11, maxX: 11, minZ: -7, maxZ: 7 },
  occupiedWorkplaces: showroomSeats(),
  ...createArchitectureAssetAdapter(runtime),
  floorY: .12, // measured production floor top; fallback floor may be .18
  signal: abortController.signal,
  strictPlacement: true,
});
scene.add(architecture); // only after complete load
console.log(architecture.diagnostics);
architecture.dispose(); // idempotent; before caller-owned shared-resource disposal
```

`PremiumArchitectureOptions`:

- `floorBounds: {minX,maxX,minZ,maxZ}` — мировые метры, Y-up; footprint около 22 × 14 или больше.
- `occupiedWorkplaces: readonly {deskId,employeeId?,x,z,bounds?,approach?}[]` — мировые координаты.
- `cloneAsset(id): Object3D | undefined | Promise<Object3D | undefined>` — независимый root без parent.
- `releaseAsset?(object): void` — нужен для владения runtime references, готовый adapter предоставляет его. При borrowed ресурсах без release callback владелец отвечает за свои экземпляры; после передачи модулю их нельзя параллельно переиспользовать.
- `floorY?: number`, default .12.
- `elevatorBounds?: {id,minX,maxX,minZ,maxZ}`, `elevatorApproach?: {x,z}` — world-space overrides для существующего лифта.
- `signal?: AbortSignal`, `strictPlacement?: boolean` (default false), `artIteration?: 1 | 2` (default 2; 1 только для сравнения).

Результат — **сама THREE.Group**, не `{group}`, с `metadata`, `diagnostics`, `assetBounds`, `dispose()`. Factory всегда асинхронный. `ArchitectureError`: `code`, `assetId?`, `diagnostics?`. При strictPlacement false конфликты явно возвращаются в diagnostics; при true сборка отклоняется с cleanup.

`metadata.replaceLegacy` перечисляет заменяемые assetId. `replaceLegacyAssemblies` — логические labels процедурных сборок, не обещание существования таких имён у старых unnamed meshes. `legacyProceduralSelection` поясняет: интегратору нужны construction-site references; нельзя скрывать весь fallbackRoot, поскольку там также столы и люди. `preserveLegacy` сохраняет пол, физический лифт, desk/monitor/keyboard, кресла сотрудников, персонажей, camera controls и floor layout engine. Модуль самостоятельно ничего из этого не скрывает и не заменяет.
