# Office Art v1 / MAO-GFX-21

`public/office-art/v1/office-pack.glb` is a small project-owned GLB pack in a right-handed, Y-up, metre coordinate system. It contains named root nodes for the furniture, materials and character states listed in `manifest.json`. The pack is intentionally modular: load one GLB lazily and clone a named node for each desk, chair or character instead of duplicating files.

```ts
const manifest = await loadOfficeManifest((url) => fetch(url))
const workstation = assetById(manifest, 'preview.workstation')
const url = workstation && resolveAssetUrl('/office-art/v1/manifest.json', workstation.url)
// GLTFLoader.load(url), then select scene.getObjectByName(workstation.node)
```

Character variants are reusable visual states, not claims about employee identity:

- `character.base.idle`
- `character.base.working`
- `character.base.selected`
- `character.base.blocked`

The pack is generated by `generate-assets.mjs` and is entirely project-owned:

```bash
node src/office-art/generate-assets.mjs
```

The generator uses the project’s installed Three.js geometry tools; it downloads no models or dependencies. It emits a single
modular GLB with reusable furniture, workstations, character states and the
elevator, plus local SVG tile textures and a versioned manifest/material
library. The current pack contains rounded/composed furniture details rather
than single placeholder cubes: monitor bezels and stands, keyboard/mouse,
ergonomic chair parts and wheels, upholstery cushions, shelving contents,
plants, glass framing and warm bronze lighting details.

The elevator is split into `elevator.cabin`, `elevator.doors`,
`elevator.frame`, `elevator.display`, `elevator.call-panel`,
`elevator.floor-sign` and `elevator.wall-lights`. Door nodes have stable
floor pivots and the GLB includes `elevator.doors.open`, a one-second linear
translation animation with separate left/right channels. Navigation and door
state orchestration remain application responsibilities.

The material library is PBR data in `materials.json` with local SVG tile
textures. It includes light oak, warm terracotta brick, cream paint, graphite
metal, brushed bronze, tinted glass, dark monitor glass, soft upholstery,
woven carpet and ceramic/leaf colors. Texture descriptors explicitly carry
sRGB, repeat wrapping and repeat factors.

## Runtime API

`createOfficeArtRuntime()` validates the manifest, rejects remote/path-escape
URLs, caches each GLB promise by resolved URL, and creates independent instances
that safely share geometry and materials:

```ts
import { createOfficeArtRuntime } from './index'

const art = createOfficeArtRuntime()
const character = await art.createCharacter('employee-001', 'working', {
  position: [0, 0, 0],
})
scene.add(character)
```

`disposeInstance()` only detaches an instance; it does not dispose shared GLB
resources used by other instances. `clearModelCache()` forgets the loader cache
for a future reload and should be called only after instances are removed.
`checkBounds()` is diagnostic and does not silently rescale authored models.
Tests and offline previews can inject a model loader and a manifest snapshot,
without network access.

## Unified material contract

`materials.json` contains an explicit `mappings` object. Its key is the
manifest material asset ID; each value names the GLB material (`glbMaterialName`)
and the library descriptor (`libraryKey`). Texture URLs are repeated in the
mapping as an integrity check and are also present on the descriptor.

```ts
const runtime = createOfficeArtRuntime()
const desk = await runtime.createInstance('desk.modern', {
  position: [2, 0, -1],
  rotation: [0, Math.PI / 2, 0],
})
await runtime.applyMaterials(desk)
scene.add(desk)

// Detaches the clone and releases the shared GLB reference. It is safe to call
// twice; shared geometry/materials are disposed only after the final owner.
runtime.disposeInstance(desk)

// Call only when no runtime instances remain. Throws if an instance is active.
runtime.disposeSharedResources()
```

The runtime does not rotate normalized assets: the pack is already canonical
right-handed Y-up, with X/Z as the floor plane. `applyMaterials()` reuses one
Three.js material and one texture promise per library key/URL, including
`SRGBColorSpace`, repeat and wrap settings. The renderer can use this API
without reproducing material-name or disposal logic.

The official Kenney Furniture Kit was reviewed as a possible source and is published as a CC0 3D asset pack: <https://kenney.nl/assets/furniture-kit>. No Kenney files are bundled in this pack, so no third-party attribution or unreviewed downloaded content is added to the build.

## GFX-28 premium pack

Blender was not installed. `generate-assets.mjs` + `premium-models.mjs` author
beveled furniture, closed cylindrical frames, rounded upholstery, individual
leaves, seated human anatomy and architectural assemblies. Stable root IDs and
Y-up metre coordinates remain unchanged. Static details are merged by material;
indexed vertices and identical meshes are deduplicated across the pack.

Character state roots expose three reusable visual variants each. The runtime
selects a variant deterministically from the authored placement (desk), preserving
employeeId and status. Moving desks can change the visual style; the variants
are presentation data, not persistent employee appearance. No runtime status,
Directory identity or selection code was changed.

The material library adds optional `doubleSided` and `emissiveFactor` fields;
glass is double sided and its image tile is fully filled. Opacity comes from the
PBR factor, avoiding compounded transparent SVG pixels. Amber lamps retain a
small emission after runtime material replacement. Both fields are optional for
older libraries. `OfficeArtRuntime.findNode` accepts GLTFLoader-sanitized names.

Door nodes retain their original local translations and openTranslation extras.
Their bronze panels now include graphite inlays as GLB material primitives under
the same animated nodes. The embedded animation now has two valid samplers with
absolute transforms. The scene's existing manual door animation remains intact.

### Reproduce visual and structural checks

```sh
node apps/office/src/office-art/generate-assets.mjs
node apps/office/src/office-art/preview-check.mjs
cd apps/office
./node_modules/.bin/vitest run src/office-art --no-cache
./node_modules/.bin/tsc --noEmit --incremental false
```

The browser runner uses installed Chromium/software WebGL, real GLTFLoader and
OfficeArtRuntime. It saves a labeled contact sheet and full-floor screenshots in
`public/office-art/comparison/`. It also measures the same current scene with the
preserved old pack served from an isolated test middleware. It does not change
the renderer or repository files outside office-art.

See `QUALITY-REPORT.md` for actual measurements and limitations. The `preview.*`
legacy composition IDs remain available for compatibility; the new contact sheet
uses the actual production furniture IDs rather than the old schematic previews.

cushions/piping, extruded through-hole desk tops, paired wheels, hollow mugs/shades
and a rounded circular table. `generate-assets.mjs` still emits a single cached
Y-up/metre GLB. All 74 GFX-28 IDs remain; one sconce model and four material/texture
IDs are added. No OfficeArtRuntime API or scene files are changed.

See `STUDIO-29-REPORT.md` and `public/office-art/studio-29/` for iterations,
before/after contact sheet, counters and the preserved GFX-28 baseline.
