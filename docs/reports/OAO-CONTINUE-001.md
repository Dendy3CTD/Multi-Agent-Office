## 4. Фактическая структура dist

`packages/budget-manager/dist/` содержит 12 файлов:

```text
budget-manager.js        budget-manager.d.ts
budget-policy.js         budget-policy.d.ts
index.js                 index.d.ts
jsonl-store.js           jsonl-store.d.ts
types.js                 types.d.ts
usage-ledger.js          usage-ledger.d.ts
```

По одной паре `.js` и `.d.ts` на каждый модуль `src/`. `index.js` — публичная
точка входа (`exports["."]`). Declaration maps и source maps отключены.

## 5. Изменения архитектурной документации

- `docs/ARCHITECTURE.md`, раздел **«Agent Terminal — Stage 9»**: Agent Terminal —
  собственный React-интерфейс, не встроенный и не скопированный TUI OpenCode;
  получает типизированные структурированные события из
  `packages/runtime-opencode`; Runtime — источник истины о состоянии сотрудников;
  интерфейс не выводит работу из разбора терминала и не симулирует активность;
  события покрывают потоковые сообщения, жизненный цикл инструментов и команд,
  результаты, ошибки, идентичность сессии/задачи/модели, тайминги и статистику;
  есть контролируемое подтверждение опасных действий и редактирование секретов.
- `docs/ROADMAP.md`, раздел **«Stage 9 — Agent Terminal»**: 8 пунктов
  (все невыполненные) — референс, собственный React-терминал, потоковые события
  Runtime, Markdown и подсветка кода, структурированные блоки, состояния и
  статистика, ввод и отмена, отдельные сессии четырёх сотрудников, подтверждение
  опасных действий и редактирование секретов.

Все требования из задания присутствуют в обоих документах.

## 6. Фиксация Agent Terminal и визуального референса

Выбранная основа интерфейса — **третье изображение** из подборки терминалов,
показанной ChatGPT 2 ноября 2026 года: тёмная современная developer-консоль,
аккуратная типографика, структурированные блоки сообщений, команд и результатов.
Стили двух других изображений не смешиваются с выбранным (зафиксировано в ROADMAP).

Проверка репозитория: файл изображения **не найден**. Поиск по `*terminal*` и
`*agent-term*` ничего не дал; PNG в `docs/` отсутствуют. Единственные PNG в
`apps/office/assets/` — иконки приложения и не являются терминальным
референсом. Поэтому в ROADMAP пункт «добавить референс» остаётся
невыполненным до добавления файла в репозиторий.

Agent Terminal **не реализован**. Компоненты, CSS, Electron, Runtime-события и
подключение Budget Manager в этой задаче не затрагивались.
